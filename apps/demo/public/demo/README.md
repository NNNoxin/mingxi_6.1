# 明晰 · 离线产品 Demo

单文件打包：**手机捕获 Demo + 网页工作台精简 Demo + 一键导览**。

## 文件

- [`mingxi-product-demo.html`](./mingxi-product-demo.html) — 双击即可离线打开

## 怎么下载到本地

1. 开发服打开：`http://localhost:3000/demo/mingxi-product-demo.html` → 点 **「下载此 HTML」**
2. 或直接复制仓库里的本文件到任意目录双击用浏览器打开

## 一键导览（推荐先看）

右上角 **「一键导览」**：按产品故事线自动演示约 15 步，聚光灯对准功能，旁白卡片写清：

- **痛点**（为何需要）
- **产品逻辑**（领域 AI / 用途人确认 / 先收下再对齐）
- **特色动作**（短按待定、长按用途、领域覆盖、梳逻辑引用）

可暂停 / 上一步 / 下一步 / Esc 结束；系统开启「减少动态效果」时改为纯手动翻步。

### 导览顺序（产品闭环）

```
痛点开场 → 原则（领域AI·用途人）→ 手机场景 → 短按待定 → 入库
→ 长按选用途 → 待定确认 → 网页工作台 → 用途切片 → 领域热力
→ Icicle → 完整笔记 → 梳逻辑线 → 引用证据 → 闭环收束
```

## 包含什么

| 侧 | 可演示 |
|---|---|
| 手机 | 桌面 → 小红书帖 → 悬浮球短按（待定）/ 长按选用途 → 笔记库 → 待定用途确认 |
| 网页 | 用途筛选 · 领域热力/Icicle · 笔记卡片详情 · 梳逻辑线引用开笔记 |

> 这是**前端高保真演示包**，不含真实 `/api/mingxi/*` 后端。完整联调请继续用 `npm run dev` 打开 `/mingxi/web` 与 `/demo/phone`。
