# 维基百科 · 间隔重复

**间隔重复**（英語：Spaced repetition）是一种利用心理学[间隔效应](https://zh.wikipedia.org/w/index.php?title=%E9%97%B4%E9%9A%94%E6%95%88%E5%BA%94&action=edit&redlink=1 "间隔效应（页面不存在）")，通过不断复习所学内容并逐步增加两次复习间的时间间隔来提升效率的[学习](https://zh.wikipedia.org/wiki/%E5%AD%A6%E4%B9%A0 "学习")技巧。[[1]](https://zh.wikipedia.org/wiki/%E9%97%B4%E9%9A%94%E9%87%8D%E5%A4%8D#cite_note-1)

间隔重复适用于诸多学习情境，特别是学习者需要牢固记忆大量知识的情形，比如外语[词汇](https://zh.wikipedia.org/wiki/%E8%AF%8D%E6%B1%87 "词汇")的学习，尤其是在目标语言的基础词汇数量很大的时候。

將间隔重复應用到学习上的观点最初見於[塞西尔·阿莱克·梅斯](https://zh.wikipedia.org/w/index.php?title=%E5%A1%9E%E8%A5%BF%E5%B0%94%C2%B7%E9%98%BF%E8%8E%B1%E5%85%8B%C2%B7%E6%A2%85%E6%96%AF&action=edit&redlink=1 "塞西尔·阿莱克·梅斯（页面不存在）")1932的著作《學習心理學》中：“那些關於恰當分佈學習時間的發現大概是最爲重要的……对知识的复习和回顾应该反复多次，并且逐渐增加时间间隔，比如一天、两天、四天、八天，以此類推。”[[2]](https://zh.wikipedia.org/wiki/%E9%97%B4%E9%9A%94%E9%87%8D%E5%A4%8D#cite_note-2)

1939年，H·F·Spitzer在[爱荷华州](https://zh.wikipedia.org/wiki/%E7%88%B1%E8%8D%B7%E5%8D%8E%E5%B7%9E "爱荷华州")对36名学生进行了一项实验，验证了间隔重复方法的效果。这一工作起初並未引起关注，直到20世纪60年代，认知心理学家[亞瑟·梅爾頓](https://zh.wikipedia.org/w/index.php?title=%E4%BA%9E%E7%91%9F%C2%B7%E6%A2%85%E7%88%BE%E9%A0%93&action=edit&redlink=1 "亞瑟·梅爾頓（页面不存在）")[[3]](https://zh.wikipedia.org/wiki/%E9%97%B4%E9%9A%94%E9%87%8D%E5%A4%8D#cite_note-3)、[托馬斯·蘭道爾](https://zh.wikipedia.org/wiki/%E6%89%98%E9%A9%AC%E6%96%AF%C2%B7%E5%85%B0%E9%81%93%E5%B0%94 "托马斯·兰道尔")及[羅伯特·A·比約克](https://zh.wikipedia.org/w/index.php?title=%E7%BE%85%E4%BC%AF%E7%89%B9%C2%B7A%C2%B7%E6%AF%94%E7%B4%84%E5%85%8B&action=edit&redlink=1 "羅伯特·A·比約克（页面不存在）")[[4]](https://zh.wikipedia.org/wiki/%E9%97%B4%E9%9A%94%E9%87%8D%E5%A4%8D#cite_note-4)再次研究了间隔时间对于复习效果的影响。大概在同一时间，[皮姆斯勒語言計畫](https://zh.wikipedia.org/wiki/%E7%9A%AE%E5%A7%86%E6%96%AF%E5%8B%92%E8%AA%9E%E8%A8%80%E5%AD%B8%E7%BF%92%E7%B3%BB%E7%B5%B1 "皮姆斯勒語言學習系統")率先决定将间隔重复理论应用于语言学习。1973年，[瑟巴斯坦·莱特纳](https://zh.wikipedia.org/wiki/%E7%91%9F%E5%B7%B4%E6%96%AF%E5%9D%A6%C2%B7%E8%90%8A%E7%89%B9%E7%B4%8D "瑟巴斯坦·萊特納")发明了他的「[莱特纳系统](https://zh.wikipedia.org/wiki/%E8%90%8A%E7%89%B9%E7%B4%8D%E7%B3%BB%E7%B5%B1 "萊特納系統")」——一种基于[抽认卡](https://zh.wikipedia.org/wiki/%E6%8A%BD%E8%AE%A4%E5%8D%A1 "抽认卡")的全功能间隔重复学习系统。

随着20世纪80年代个人计算机的普及，基于间隔重复方法的软件被广泛应用于[计算机辅助语言学习](https://zh.wikipedia.org/w/index.php?title=%E8%AE%A1%E7%AE%97%E6%9C%BA%E8%BE%85%E5%8A%A9%E8%AF%AD%E8%A8%80%E5%AD%A6%E4%B9%A0&action=edit&redlink=1 "计算机辅助语言学习（页面不存在）")。通过软件的自动发放和统计，学习者可以通过间隔重复的方法辨认数以千计的抽认卡。[[5]](https://zh.wikipedia.org/wiki/%E9%97%B4%E9%9A%94%E9%87%8D%E5%A4%8D#cite_note-5) 为了使用户达到目标水平（例如，在任何给定时间点正确辨认90％的卡片），软件会调整重复的时间间隔。难以辨认的词汇经常出现，并且简单词汇出现频率较低，其词汇难度由软件根据用户的辨认正确率确定。
