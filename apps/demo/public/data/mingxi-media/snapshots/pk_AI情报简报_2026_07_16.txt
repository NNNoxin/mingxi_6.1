Training Data: Anthropic 平台负责人 Katelyn Lesse & Angela Jiang — 构建生态系统，而
非围墙花园
核心要点：Anthropic 平台团队正在从”知识层 → 执行层 → 协调层”的路径推进抽象层级。协调层是最新方
向——当你需要给不同 token 分配不同角色（比如一个负责建议、一个负责执行），就需要编排策略
（orchestrated strategies）来组合它们。
关键引言： > “The coordination layer is almost like a meta harness. The true low level harness is
designed for execution. But the next one is about composing orchestrated strategies that go together,
and they should sit on top of all these things because at the end of the day, still need to execute.”
开发者视角：Anthropic 平台同时服务内外部——对外提供 API 和开发者平台，对内运行产品基础设施。这意
味着 Anthropic 的 API 能力与其内部产品能力是同源的，开发者可以期待与 Claude.ai 产品同等的底层能
力。
