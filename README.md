# 明晰 6.1

明晰是一款 AI 智能笔记产品：手机上 1 秒收下任何内容并由人说清“为什么留下”，网页上把零散笔记梳成可追溯的逻辑图（**梳逻辑 Agent**），并从一篇笔记出发找到知识库还没覆盖的相邻知识（**知识补全 Agent**）。

本仓库把此前分散在三个仓库里的产品 Demo 与两个 Agent 原型，整理成一个面向全站上线的统一项目。
